# Exploratory Data Analysis Practicum

This repository contains my coursework, practical exercises, notes, and data analysis implementations for the **Exploratory Data Analysis Practicum**.

The practicum covers data organization, data management, basic statistics, analysis of variance (ANOVA), mean testing, and data visualization using various data analysis and statistical software, including Microsoft Excel, SPSS, Minitab, R, and Tableau.

## Learning Objectives

Through this practicum, I developed skills in:

* Understanding and organizing data using various data analysis tools.
* Managing and manipulating datasets.
* Performing basic statistical analysis.
* Conducting analysis of variance (ANOVA).
* Performing mean testing using R.
* Creating and interpreting data visualizations.
* Applying different statistical software and tools to analyze and present data.
